Read the local AGENTS.md before editing in a subdirectory that has one. Follow the board workflow in docs/BOARD.md for all PR and issue work.

Designated session agents may make repository decisions and automatically
squash-merge individually eligible team PRs through the existing guarded helper.
No repeated human merge authorization is needed. Independent exact-head/base
review, relevant passing checks and all board gates remain required. Spending,
live flight, deployment and access changes still need human approval.
